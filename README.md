# 🏦 Emirates Bank Customer Churn Analysis

This project analyzes customer churn patterns at Emirates Bank using SQL and Power BI. It explores factors contributing to customer exits and provides actionable insights to help improve retention.

## 📌 Key Metrics

- Total Customers: 9,940
- Total Churned: 2,038 (50%)
- Average Age: 38.92
- Average Estimated Salary: 100,090.24
- Average Credit Score: 650.53

## 🔍 Major Insights

- **Higher Churn in Females**: Female exit rate is 25.07% vs. 16.47% for males.
- **Satisfaction Matters**: Customers with satisfaction scores of 1 and 2 churned most.
- **Card Type Matters**: Diamond card users had the highest churn rate.
- **Age Factor**: Churn highest among age groups 46–55 and 56–65.
- **Complaints Are Red Flags**: Complaining customers are more likely to churn.
- **Geography Matters**: German customers churned more than French and Spanish customers.
